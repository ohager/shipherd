# shipherd Plan 2 — Web Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A kanban web dashboard on `127.0.0.1`, served by the same `shipherd` process, with a detail panel (live output, pane facts, approve/deny/reply) and a token-guarded interact mode that types into the agent's pane.

**Architecture:** A new `web` module. `server.rs` is an axum router whose `guard` middleware enforces Host, token/cookie and Origin before any handler runs. Each browser WebSocket gets a `Session` — pure logic that turns fleet snapshots into messages and browser messages into effects — driven by a small async loop in `socket.rs`. All input still goes through `actions::execute` via the `runtime::Handle`; interact-mode keystrokes become a new `Action::Keys`.

**Tech Stack:** axum (`ws` feature), rand, serde; dev: tower (`util`), tokio-tungstenite, futures-util. Frontend: hand-written HTML/CSS/JS embedded with `include_str!`, no build step.

**Spec:** `docs/superpowers/specs/2026-11-13-shipherd-design.md`. **Depends on:** Plan 1 (merged).

**Decisions made while planning** (Task 10 writes them into the spec):
- Kanban cards show the agent's **task title** (tty7's `osc_title` minus the spinner glyph, e.g. "Run ls -la") instead of preview lines. Preview lines would mean capturing every pane 2–3 times a second while the page is open; the title is free in the event stream.
- `tty7 procs` port entries are passed through untyped (no listening port has been recorded yet); the page shows `port` if present, else the raw JSON.
- `w` opens the login link with `open` / `xdg-open`, so the token is briefly visible in `ps` to other local users. Acceptable for a single-user machine; noted in the spec.

**Rust notes:** `axum` handlers are async functions whose arguments are "extractors" (`State`, `Query`, `WebSocketUpgrade`) — axum fills them from the request, a bit like Express middleware populating `req`. `tower::ServiceExt::oneshot` sends one request through a router in tests without opening a socket.

impl Outcome {
    /// One-line explanation for the views; `None` when there's nothing worth saying.
    pub fn message(&self) -> Option<String> {
        match self {
            Outcome::Sent => None,
            Outcome::NotReady { status: Some(status) } => {
                Some(format!("agent moved on (now {})", status.label()))
            }
            Outcome::NotReady { status: None } => Some("agent is gone".into()),
            Outcome::UnknownPane => Some("that pane is gone".into()),
            Outcome::Unsupported => Some("not supported for this agent".into()),
            Outcome::Rejected(reason) => Some(format!("rejected: {reason}")),
            Outcome::Failed(err) => Some(format!("failed: {err}")),
        }
    }
}

/// One keystroke group from the browser: literal text, or a key name tty7 understands.
#[derive(Debug, Clone, PartialEq, Eq, Deserialize)]
#[serde(tag = "kind", content = "value", rename_all = "snake_case")]
pub enum KeyInput {
    Text(String),
    Key(String),
}

const NAMED_KEYS: &[&str] = &[
    "enter", "escape", "tab", "backtab", "space", "backspace", "delete", "up", "down", "right",
    "left", "home", "end", "pageup", "pagedown",
];
const MAX_TEXT: usize = 4096;

/// Control characters must arrive as named keys, so text can't smuggle in escape sequences.
fn validate(keys: &[KeyInput]) -> Result<(), String> {
    if keys.is_empty() {
        return Err("no keys".into());
    }
    for key in keys {
        match key {
            KeyInput::Text(text) => {
                if text.is_empty() || text.len() > MAX_TEXT || text.chars().any(char::is_control) {
                    return Err("invalid text".into());
                }
            }
            KeyInput::Key(name) => {
                if !(NAMED_KEYS.contains(&name.as_str()) || is_modified_key(name)) {
                    return Err(format!("unknown key {name}"));
                }
            }
        }
    }
    Ok(())
}

/// `C-x` (Ctrl) or `M-x` (Alt) with a single ASCII letter or digit.
fn is_modified_key(name: &str) -> bool {
    let mut chars = name.chars();
    matches!(
        (chars.next(), chars.next(), chars.next(), chars.next()),
        (Some('C' | 'M'), Some('-'), Some(c), None) if c.is_ascii_alphanumeric()
    )
}

async fn send_interactive(cli: &dyn Tty7Cli, pane: u32, keys: &[KeyInput]) -> Outcome {
    if let Err(reason) = validate(keys) {
        return Outcome::Rejected(reason);
    }
    for key in keys {
        let result = match key {
            KeyInput::Text(text) => cli.send_text(pane, text, false).await,
            KeyInput::Key(name) => cli.send_keys(pane, &[name.as_str()]).await,
        };
        if let Err(err) = result {
            return Outcome::Failed(err.to_string());
        }
    }
    Outcome::Sent
}

//! Pure checks for the web server's three gates: Host, token, Origin.

pub const COOKIE: &str = "shipherd";

/// 256 random bits as hex, generated once per run.
pub fn new_token() -> String {
    let bytes: [u8; 32] = rand::random();
    bytes.iter().map(|b| format!("{b:02x}")).collect()
}

/// Constant-time, so response timing doesn't reveal how much of a guess was right.
pub fn token_matches(given: &str, expected: &str) -> bool {
    given.len() == expected.len()
        && given
            .bytes()
            .zip(expected.bytes())
            .fold(0u8, |acc, (a, b)| acc | (a ^ b))
            == 0
}

/// Rejecting other Host values defeats DNS rebinding, where an attacker's domain resolves to 127.0.0.1.
pub fn host_allowed(host: Option<&str>, port: u16) -> bool {
    host.is_some_and(|h| h == format!("127.0.0.1:{port}") || h == format!("localhost:{port}"))
}

/// Browsers always send Origin on WebSocket upgrades; only our own page may connect.
pub fn origin_allowed(origin: Option<&str>, port: u16) -> bool {
    origin.is_some_and(|o| o == format!("http://127.0.0.1:{port}") || o == format!("http://localhost:{port}"))
}

pub fn cookie_token(header: Option<&str>) -> Option<&str> {
    header?
        .split(';')
        .map(str::trim)
        .find_map(|pair| pair.strip_prefix(COOKIE)?.strip_prefix('='))
}

pub fn query_token(query: &str) -> Option<&str> {
    query.split('&').find_map(|pair| pair.strip_prefix("token="))
}

//! Per-browser state. Pure: the socket loop feeds it messages and the clock, and executes its effects.

use std::time::{Duration, Instant};

use super::protocol::{AgentView, ClientMsg, ServerMsg};
use crate::actions::{Action, KeyInput};
use crate::fleet::Fleet;

pub const INTERACT_IDLE: Duration = Duration::from_secs(120);

#[derive(Debug, Clone, PartialEq)]
pub enum Effect {
    Watch(Option<u32>),
    Act { id: u64, action: Action },
    Keys { pane: u32, keys: Vec<KeyInput> },
    Send(ServerMsg),
}

#[derive(Default)]
pub struct Session {
    selected: Option<u32>,
    /// The pane keystrokes may go to, and when the last one arrived.
    interact: Option<(u32, Instant)>,
    last_snapshot: Option<(Vec<AgentView>, Vec<String>)>,
    last_preview: Option<String>,
}

impl Session {
    pub fn selected(&self) -> Option<u32> {
        self.selected
    }

    pub fn on_client(&mut self, msg: ClientMsg, now: Instant) -> Vec<Effect> {
        match msg {
            ClientMsg::Watch { pane } => {
                let mut effects = self.end_interact_unless(pane);
                self.selected = pane;
                self.last_preview = None;
                effects.push(Effect::Watch(pane));
                effects
            }
            ClientMsg::Approve { id, pane } => vec![Effect::Act { id, action: Action::Approve { pane } }],
            ClientMsg::Deny { id, pane } => vec![Effect::Act { id, action: Action::Deny { pane } }],
            ClientMsg::Reply { id, pane, text } => {
                vec![Effect::Act { id, action: Action::Reply { pane, text } }]
            }
            ClientMsg::Interact { pane, on } => {
                if on && self.selected == Some(pane) {
                    self.interact = Some((pane, now));
                    vec![Effect::Send(ServerMsg::Interact { pane, on: true })]
                } else {
                    if self.interact.is_some_and(|(p, _)| p == pane) {
                        self.interact = None;
                    }
                    vec![Effect::Send(ServerMsg::Interact { pane, on: false })]
                }
            }
            ClientMsg::Keys { pane, keys } => match self.interact {
                Some((p, last)) if p == pane && now.duration_since(last) < INTERACT_IDLE => {
                    self.interact = Some((pane, now));
                    vec![Effect::Keys { pane, keys }]
                }
                _ => vec![Effect::Send(ServerMsg::Interact { pane, on: false })],
            },
        }
    }

    /// Messages the page needs after a fleet change or a clock tick.
    pub fn updates(&mut self, fleet: &Fleet, now: Instant) -> Vec<ServerMsg> {
        let mut out = Vec::new();
        if let Some((pane, last)) = self.interact
            && (now.duration_since(last) >= INTERACT_IDLE || !fleet.panes.contains_key(&pane))
        {
            self.interact = None;
            out.push(ServerMsg::Interact { pane, on: false });
        }

        let agents: Vec<AgentView> = fleet.ordered().into_iter().map(AgentView::from).collect();
        let snapshot = (agents, fleet.banners());
        if self.last_snapshot.as_ref() != Some(&snapshot) {
            out.push(ServerMsg::Snapshot { agents: snapshot.0.clone(), banners: snapshot.1.clone() });
            self.last_snapshot = Some(snapshot);
        }

        if let Some(pane) = self.selected
            && let Some(text) = fleet.panes.get(&pane).and_then(|p| p.preview.as_ref())
            && self.last_preview.as_ref() != Some(text)
        {
            out.push(ServerMsg::Preview { pane, text: text.clone() });
            self.last_preview = Some(text.clone());
        }
        out
    }

    fn end_interact_unless(&mut self, pane: Option<u32>) -> Vec<Effect> {
        match self.interact {
            Some((p, _)) if Some(p) != pane => {
                self.interact = None;
                vec![Effect::Send(ServerMsg::Interact { pane: p, on: false })]
            }
            _ => Vec::new(),
        }
    }
}

//! Routes, plus the guard that every request passes first.

use std::sync::Arc;
use std::sync::atomic::AtomicU64;

use axum::Router;
use axum::extract::{Request, State};
use axum::http::{HeaderMap, HeaderName, StatusCode, header};
use axum::middleware::{self, Next};
use axum::response::{Html, IntoResponse, Response};
use axum::routing::get;

use super::auth;
use crate::runtime::Handle;

const INDEX_HTML: &str = include_str!("assets/index.html");
const APP_CSS: &str = include_str!("assets/app.css");
const APP_JS: &str = include_str!("assets/app.js");

#[derive(Clone)]
pub struct AppState {
    pub handle: Handle,
    pub token: Arc<str>,
    pub port: u16,
    pub next_client: Arc<AtomicU64>,
}

impl AppState {
    pub fn new(handle: Handle, token: Arc<str>, port: u16) -> Self {
        AppState { handle, token, port, next_client: Arc::new(AtomicU64::new(1)) }
    }
}

pub fn router(state: AppState) -> Router {
    Router::new()
        .route("/", get(|| async { Html(INDEX_HTML) }))
        .route("/app.css", get(|| async { ([(header::CONTENT_TYPE, "text/css; charset=utf-8")], APP_CSS) }))
        .route(
            "/app.js",
            get(|| async { ([(header::CONTENT_TYPE, "text/javascript; charset=utf-8")], APP_JS) }),
        )
        .layer(middleware::from_fn_with_state(state.clone(), guard))
        .with_state(state)
}

enum Verdict {
    Pass,
    Login,
    Unauthorized,
    Forbidden(&'static str),
}

fn header_str<'a>(headers: &'a HeaderMap, name: HeaderName) -> Option<&'a str> {
    headers.get(name).and_then(|v| v.to_str().ok())
}

fn verdict(request: &Request, state: &AppState) -> Verdict {
    let headers = request.headers();
    if !auth::host_allowed(header_str(headers, header::HOST), state.port) {
        return Verdict::Forbidden("forbidden host");
    }
    let path = request.uri().path();
    if path == "/"
        && let Some(token) = request.uri().query().and_then(auth::query_token)
    {
        return if auth::token_matches(token, &state.token) {
            Verdict::Login
        } else {
            Verdict::Unauthorized
        };
    }
    let has_cookie = auth::cookie_token(header_str(headers, header::COOKIE))
        .is_some_and(|token| auth::token_matches(token, &state.token));
    if !has_cookie {
        return Verdict::Unauthorized;
    }
    if path == "/ws" && !auth::origin_allowed(header_str(headers, header::ORIGIN), state.port) {
        return Verdict::Forbidden("forbidden origin");
    }
    Verdict::Pass
}

async fn guard(State(state): State<AppState>, request: Request, next: Next) -> Response {
    match verdict(&request, &state) {
        Verdict::Pass => next.run(request).await,
        // Swapping the URL token for a cookie takes it out of the address bar and history.
        Verdict::Login => {
            let cookie = format!("{}={}; HttpOnly; SameSite=Strict; Path=/", auth::COOKIE, state.token);
            (StatusCode::SEE_OTHER, [(header::LOCATION, "/".to_string()), (header::SET_COOKIE, cookie)])
                .into_response()
        }
        Verdict::Unauthorized => (
            StatusCode::UNAUTHORIZED,
            "Open the dashboard from shipherd's terminal UI (press w).",
        )
            .into_response(),
        Verdict::Forbidden(reason) => (StatusCode::FORBIDDEN, reason).into_response(),
    }
}

use std::sync::atomic::Ordering;
use std::time::{Duration, Instant};

use axum::extract::ws::{Message, WebSocket};
use axum::extract::{State, WebSocketUpgrade};
use axum::response::Response;
use tokio::time::interval;
use tracing::{debug, warn};

use super::protocol::{ClientMsg, ServerMsg};
use super::server::AppState;
use super::session::{Effect, Session};
use crate::actions::{Action, Outcome};
use crate::runtime::Handle;

const PROCS_EVERY: Duration = Duration::from_secs(2);

pub async fn upgrade(State(state): State<AppState>, ws: WebSocketUpgrade) -> Response {
    let client = format!("web-{}", state.next_client.fetch_add(1, Ordering::Relaxed));
    let handle = state.handle.clone();
    ws.on_upgrade(move |socket| run(socket, handle, client))
}

async fn run(mut socket: WebSocket, handle: Handle, client: String) {
    if let Err(err) = session_loop(&mut socket, &handle, &client).await {
        debug!("web session {client} ended: {err:#}");
    }
    handle.watch(&client, HashSet::new()).await;
}

async fn session_loop(socket: &mut WebSocket, handle: &Handle, client: &str) -> anyhow::Result<()> {
    let mut snapshots = handle.snapshots.clone();
    let mut session = Session::default();
    // Also drives the interact-mode idle timeout.
    let mut clock = interval(Duration::from_secs(1));
    let mut procs_tick = interval(PROCS_EVERY);

    loop {
        let fleet = snapshots.borrow_and_update().clone();
        for msg in session.updates(&fleet, Instant::now()) {
            send(socket, &msg).await?;
        }

        tokio::select! {
            changed = snapshots.changed() => changed?,
            _ = clock.tick() => {}
            _ = procs_tick.tick() => {
                if let Some(pane) = session.selected()
                    && let Some(resp) = handle.procs(pane).await
                {
                    send(socket, &ServerMsg::Procs { pane, procs: resp.procs, ports: resp.ports }).await?;
                }
            }
            incoming = socket.recv() => {
                let Some(message) = incoming else { return Ok(()) };
                let Message::Text(text) = message? else { continue };
                let msg: ClientMsg = match serde_json::from_str(&text) {
                    Ok(msg) => msg,
                    Err(err) => {
                        warn!("ignoring malformed browser message: {err}");
                        continue;
                    }
                };
                for effect in session.on_client(msg, Instant::now()) {
                    match effect {
                        Effect::Watch(pane) => handle.watch(client, pane.into_iter().collect()).await,
                        Effect::Send(msg) => send(socket, &msg).await?,
                        Effect::Act { id, action } => {
                            let outcome = handle.act(action).await;
                            let ok = outcome == Outcome::Sent;
                            send(socket, &ServerMsg::ActionResult { id, ok, message: outcome.message() }).await?;
                        }
                        Effect::Keys { pane, keys } => {
                            let outcome = handle.act(Action::Keys { pane, keys }).await;
                            if outcome != Outcome::Sent {
                                let msg = ServerMsg::ActionResult { id: 0, ok: false, message: outcome.message() };
                                send(socket, &msg).await?;
                            }
                        }
                    }
                }
            }
        }
    }
}

async fn send(socket: &mut WebSocket, msg: &ServerMsg) -> anyhow::Result<()> {
    socket.send(Message::Text(serde_json::to_string(msg)?.into())).await?;
    Ok(())
}

use std::sync::Arc;

use tokio::net::TcpListener;
use tracing::warn;

use crate::runtime::Handle;

pub struct WebServer {
    pub port: u16,
    token: Arc<str>,
}

impl WebServer {
    pub fn url(&self) -> String {
        format!("http://127.0.0.1:{}", self.port)
    }

    /// One-time link that swaps the token for a cookie.
    pub fn login_url(&self) -> String {
        format!("{}/?token={}", self.url(), self.token)
    }
}

/// Binds 127.0.0.1 only. Falls back to a free port when `preferred_port` is taken.
pub async fn start(handle: Handle, preferred_port: u16) -> anyhow::Result<WebServer> {
    let listener = match TcpListener::bind((Ipv4Addr::LOCALHOST, preferred_port)).await {
        Ok(listener) => listener,
        Err(err) => {
            warn!("port {preferred_port} unavailable ({err}); using a free port");
            TcpListener::bind((Ipv4Addr::LOCALHOST, 0)).await?
        }
    };
    let port = listener.local_addr()?.port();
    let token: Arc<str> = auth::new_token().into();
    let app = server::router(server::AppState::new(handle, token.clone(), port));
    tokio::spawn(async move {
        if let Err(err) = axum::serve(listener, app).await {
            warn!("web server stopped: {err}");
        }
    });
    Ok(WebServer { port, token })
}

function setInteracting(on, notify) {
  const changed = state.interacting !== on;
  state.interacting = on;
  $("d-interact").checked = on;
  $("detail").classList.toggle("interacting", on);
  $("d-interact-label").hidden = !on;
  if (notify && changed && state.selected !== null) send({ type: "interact", pane: state.selected, on });
}

function toKey(event) {
  if (event.key === "Tab" && event.shiftKey) return { kind: "key", value: "backtab" };
  if (NAMED_KEYS[event.key]) return { kind: "key", value: NAMED_KEYS[event.key] };
  if ((event.ctrlKey || event.altKey) && !event.metaKey && /^[a-z0-9]$/i.test(event.key)) {
    return { kind: "key", value: `${event.ctrlKey ? "C" : "M"}-${event.key.toLowerCase()}` };
  }
  // Leave browser shortcuts (Cmd+R, Cmd+C, …) alone.
  if (event.metaKey || event.ctrlKey || event.altKey) return null;
  if (event.key.length === 1) return { kind: "text", value: event.key };
  return null;
}

function mergeText(keys) {
  const merged = [];
  for (const key of keys) {
    const last = merged[merged.length - 1];
    if (key.kind === "text" && last && last.kind === "text") last.value += key.value;
    else merged.push({ ...key });
  }
  return merged;
}

// Batches keystrokes so fast typing becomes one message instead of one per key.
function flushKeys() {
  flushTimer = null;
  const keys = mergeText(pendingKeys);
  pendingKeys = [];
  if (keys.length && state.interacting && state.selected !== null) {
    send({ type: "keys", pane: state.selected, keys });
  }
}

document.addEventListener("keydown", (event) => {
  if (!state.interacting) return;
  const key = toKey(event);
  if (!key) return;
  event.preventDefault();
  pendingKeys.push(key);
  if (!flushTimer) flushTimer = setTimeout(flushKeys, 60);
});

  event.preventDefault();
  const input = $("d-reply-text");
  const text = input.value.trim();
  if (!text) return;
  act("reply", state.selected, text);
  input.value = "";
};
$("d-interact").onchange = (event) => {
  setInteracting(event.target.checked, true);
  event.target.blur();
};

use std::io::ErrorKind;
use std::process::{Command, exit};
use std::sync::Arc;

use anyhow::{Context, bail};
use shipherd::tty7::cli::RealCli;
use shipherd::{logging, runtime, tui, web};

const DEFAULT_PORT: u16 = 7777;

fn parse_port() -> anyhow::Result<u16> {
    let mut args = std::env::args().skip(1);
    match (args.next().as_deref(), args.next(), args.next()) {
        (None, _, _) => Ok(DEFAULT_PORT),
        (Some("--port"), Some(port), None) => port.parse().context("--port expects a number"),
        _ => bail!("usage: shipherd [--port N]"),
    }
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let port = parse_port()?;
    if let Err(err) = Command::new("tty7").arg("--version").output()
        && err.kind() == ErrorKind::NotFound
    {
        eprintln!("shipherd needs the tty7 CLI on your PATH. Install tty7 from https://tty7.io");
        exit(1);
    }
    let _log_guard = logging::init()?;
    let handle = runtime::start(Arc::new(RealCli));
    let server = web::start(handle.clone(), port).await?;
    let links = tui::WebLinks { url: server.url(), login: server.login_url() };
    tui::run(handle, Some(links)).await
}
